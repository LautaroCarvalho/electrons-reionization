Status codes, as this project defines them — the column exists to separate four very different kinds of number that a bare citation makes look alike.
V
verified numerically against a source that is in papers/
C
cited, but the implementation has never been checked against the source's equations
D
derived in this project from other entries
S
a scanned parameter — a range, not a measurement
U
the author's choice; no external source claimed
X
conventional in the field, but this project has established no source
